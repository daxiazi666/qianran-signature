# 签然 · 免费电子签名

纯静态的手机与电脑签名工具。手写签名后下载透明底或白底 PNG，支持撤销、重做、裁剪和笔色粗细调整。无需注册，没有付费 API、数据库、第三方字体或脚本。

签名只在当前浏览器内处理，不会提交到服务器。刷新页面会清空笔迹，离开前请下载。

## 发布到 GitHub Pages

1. 创建一个公开仓库，将本目录文件上传到仓库根目录。
2. 打开仓库 Settings → Pages。
3. Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，点击 Save。
4. 等待构建完成后，用 Pages 显示的 HTTPS 网址分享。

GitHub Free 支持公开仓库的 Pages 托管。具体配额与条件见 https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages 。

## 离线使用

下载全部文件后，打开 index.html 即可书写和导出。分享链接功能需要通过 HTTP(S) 访问。
